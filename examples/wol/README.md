# Worked example: the Web of Life tree

Scripts, in the order to run them:

| Script | Does | Writes |
|---|---|---|
| `fetch_data.py` | downloads pinned inputs, verifies SHA-256 | `data/` (git-ignored, ~40 MB) |
| `phenotypes.py` | five binary phenotypes on up to 5,417 genomes | `results/phenotypes/` |
| `gene_families.py` | presence/absence of 413 KEGG orthologues on 4,431 genomes | `results/gene_families.tsv` |
| `summarise.py` | headline numbers quoted in the top-level README | stdout |
| `make_figure.py` | the summary figure | `gene_families_{light,dark}.png` |

All runs are seeded. Per-node tables for the phenotypes (`nodes.tsv`, a few MB
each) are regenerated by `phenotypes.py` and not committed.

## Data sources

| File | Source | Version | Licence |
|---|---|---|---|
| `astral.cons.nid.nwk`, `metadata.tsv.xz` | Web of Life, <https://github.com/biocore/wol> (Zhu et al. 2019) | commit `ff92d22` | BSD 3-Clause |
| `condensed_species_NCBI.csv` | <https://github.com/bacteria-archaea-traits/bacteria-archaea-traits> (Madin et al. 2020) | commit `396dcd4` | see the repository and the data descriptor |
| `ko.txt.gz`, `ko_info.tsv.gz` | PICRUSt2 reference files, <https://github.com/picrust/picrust2> (Douglas et al. 2020) | tag `v2.5.2` | GPL-3.0 |

The tree is the ASTRAL species tree with branch lengths in substitutions per
site estimated on conserved sites, node IDs as internal labels. Genomes are
joined to phenotypes by NCBI species taxonomy ID and to KO profiles by IMG
genome ID, both taken from the Web of Life metadata.

## Coding decisions

- Phenotypes are reduced to two states (see `TRAITS` in `phenotypes.py`);
  species with other or missing values are dropped. Facultative and
  microaerophilic organisms have no natural place in a binary oxygen trait, so
  oxygen requirement is not included.
- A KO is "present" if its copy number is at least one.
- Branch lengths are floored at 1e-6 because a few genomes are effectively
  identical in the tree and would otherwise make differing states impossible.
- Named ancestors are the MRCA of all analysed genomes (root) and of those
  labelled Bacteria or Archaea in the NCBI taxonomy.
